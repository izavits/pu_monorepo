# iFPNU

> PU learning project

Experiment with various PU learning methods including PU risk estimators, PNU risk estimators, one-step and two-step techniques.

## Table of Contents

- [Install](#install)
- [Usage](#usage)
- [Support](#support)
- [Contributing](#contributing)


## Install
- Create your virtual environment and install the required dependencies:

```
virtualenv -p `which python3` venv
source venv/bin/activate
pip install -r requirements.txt
``` 

## Usage

- Edit the `config.ini` file to configure the experimental setting.
- Run `main*.py` to experiment with the various datasets and methods or with the real world application.
