# iFPNU

> iFPNU: Focused PU learning from imbalanced data

PU and PNU risk estimators, one-step and two-step techniques.

## Table of Contents

- [Install](#install)
- [Usage](#usage)


## Install
- Create your virtual environment and install the required dependencies:

```
virtualenv -p `which python3` venv
source venv/bin/activate
pip install -r requirements.txt
``` 

## Usage

- Edit the `config.ini` file to configure the experimental setting.
- Run `main*.py` to experiment with the various datasets and methods.

This project is under heavy development. At this point, PRs are accepted only from team members.
